# Lumen Lane Cycles service handbook (FICTIONAL)

Lumen Lane Cycles is an invented bicycle shop with an online store and a bike-care subscription.
The company, people, customers, orders, incidents and policies in this folder are made up for the
OpsDesk demo. They do not describe any real business or employer.

Each file is one handbook document. Front matter gives the document id, version, effective date
and category. Each `## HB-...` section is a citable passage with its keywords, the action it
permits (if any) and, for old versions, the passage that replaces it.
